# Privacy Policy – Clean Copy

Effective Date: [2026-02-20]

Clean Copy ("the Extension") is designed to respect your privacy.

## 1. Data Collection

Clean Copy does NOT collect, store, transmit, or sell any personal information.

The extension does not track browsing activity, user identity, or usage analytics.

## 2. Data Processing

All text processing happens locally within your browser.

Selected text is cleaned and copied directly on your device. No data is sent to external servers.

## 3. Storage Usage

The extension uses Chrome's storage API only to save user preferences such as:

- Cleaning settings
- Interface options
- Local usage counters (for example: texts cleaned)

This data remains stored locally in your browser profile.

## 4. Third-Party Services

Clean Copy does not use third-party analytics, tracking scripts, or external APIs.

## 5. Permissions Explanation

The extension may request the following permissions:

- **Storage** — to save user settings locally.
- **Active Tab / Scripting** — to process selected text when the user activates the extension.
- **Context Menus** — to add the "Copy Clean" right-click option.

These permissions are used solely to provide core functionality.

## 6. Data Sharing

No data is shared with third parties.

## 7. Changes to This Policy

This Privacy Policy may be updated from time to time. Updates will be reflected on this page.

## 8. Contact

If you have questions regarding this Privacy Policy, please contact the developer via the Chrome Web Store listing.
